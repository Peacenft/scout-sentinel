# Binance Agent OS Mini Hackathon, Track A

Scout proposes. Sentinel decides.

Scout is a read-only opportunity hunter. Sentinel is a deterministic risk and permission layer. It rejects unsafe proposals, requires exact user approval, records an audit chain, and keeps execution disabled until a real Binance Agentic account connection and trusted provider checks are present.
